#Project Description
---
This project's goal is to develop a BLE Mesh based system that can be used to remotely control Air conditioners at public places. 

## Prerequisites & Stack used: 
---
- Espressif SDK
- Arduino Environment
- BLE Mesh
- IRremoteESP8266 Library
- EC200U LTE communication
- MQTT
